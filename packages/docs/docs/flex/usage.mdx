# Usage

Here is a simple **Sortable Flex** usage example. For more specific usage scenarios, see the [Examples](./examples) section.

There are **no required props** for the `Sortable.Flex` component and you can **render anything** within it. Items **don't have to be the same components** and **don't need to have the same height**.

## Basic Example

```tsx
import { Text, View, StyleSheet } from 'react-native';
import Sortable from 'react-native-sortables';

const DATA = [
  'Poland',
  'Germany',
  'France',
  'Italy',
  'Spain',
  'Portugal',
  'Greece',
  'Great Britain',
  'United States',
  'Canada',
  'Australia',
  'New Zealand'
];

export default function Flex() {
  return (
    <Sortable.Flex gap={10} padding={10}>
      {/* You can render anything within the Sortable.Flex component */}
      {DATA.map(item => (
        <View style={styles.cell} key={item}>
          <Text>{item}</Text>
        </View>
      ))}
    </Sortable.Flex>
  );
}

const styles = StyleSheet.create({
  cell: {
    backgroundColor: '#36877F',
    borderRadius: 9999,
    padding: 10,
    alignItems: 'center',
    justifyContent: 'center'
  }
});
```

## Details

To create a sortable flex container, you need to import the `Sortable` object from the `react-native-sortables` package and then, use the `Sortable.Flex` component.

The `Sortable.Flex` component has no required props. Pass the items as its `children` and give every child a unique `key`, which identifies the item when items are reordered.

You can customize the flex appearance and behavior by using other props. See the [Props](./props) section for more information.
